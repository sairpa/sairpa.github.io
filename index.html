Palladium OS



Palladium OS (abbreviated pdOS), is a Custom ROM based on Android 11 and the element palladium. It isn't yet another ubiquitous ROM. pdOS is speed and stability at its finest. But the game-changer here is that this is a community-driven OS. Anyone can request or remove a feature. This is implemented by a system app, the pdC ( pdOS Community) with which the users can interact/create polls and posts for discussion. Exclusive OTAs which add new features and easter eggs inside the OS based on the suggestions from pdC.
